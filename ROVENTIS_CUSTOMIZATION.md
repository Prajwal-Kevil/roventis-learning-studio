# Roventis Technologies customization

This repository is a Roventis Technologies product workspace built from [HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor).

## Product identity

- Product: **Roventis Learning Studio**
- Company: **Roventis Technologies**
- Maintainer: **Prajwal C**
- Focus: branded learning, research, knowledge, and productivity software for Roventis customers

## What Roventis adds

- A professional Roventis product narrative and onboarding path.
- A company-oriented starter profile for website, app, SaaS, and desktop-software teams.
- Documentation that separates upstream functionality from Roventis-specific customization.
- A clean foundation for future Roventis modules, integrations, and customer deployments.

The core application remains compatible with the upstream DeepTutor installation and configuration model. Product-level changes should be kept in clearly named Roventis files or documented commits so future upstream updates can be merged safely.
